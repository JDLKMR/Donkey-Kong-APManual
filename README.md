# Donkey Kong Manual APWorld
This is a small, simple Manual for the original Donkey Kong. There are three versions, as items/level counts differ between them all: one for NES, Original Edition, and Arcade.

## Items
- Progressive Level Unlocks
- Hammer

## Locations
- Levels clears
- Parasols
- Purses
- Hats

## Goal
- Clear the final level
